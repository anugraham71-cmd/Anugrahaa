# Anugraha Madhu Portfolio

A responsive portfolio website recreated from the uploaded portfolio presentation.

## Design
- Poppins for the bold/clean typography
- Tangerine for the large handwritten script
- Lustria for the About section body copy
- Cream + deep red palette
- Bow and cherry artwork extracted from the supplied presentation
- Full-screen sections with responsive layouts
- Smooth navigation and active-section highlighting

## Run
Open `index.html` in a browser.

For best results, serve the folder with a small local server, e.g.:
`python -m http.server`

The Google Fonts import requires an internet connection. If you need a fully offline version, replace the font imports with locally licensed font files.
